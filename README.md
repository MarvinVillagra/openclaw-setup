# OpenClaw Model Updates

Public reference for the model IDs and routing currently used with OpenClaw. This repository contains only model IDs, provider routing, and update notes. It contains no API keys or host-specific setup details.

- Current model snapshot: [`models/models.json`](models/models.json)
- Update history: [`UPDATES.md`](UPDATES.md)

Model names and provider access can change. Verify availability for your own account before relying on this snapshot. This repository records configuration; it does not deploy or modify an OpenClaw installation.
